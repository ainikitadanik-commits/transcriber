# Область и требования

Статус: нормативная спецификация
Актуально на: 2026-07-20

## Обозначения

- `MUST` — обязательное требование.
- `SHOULD` — ожидаемое поведение; отклонение требует объяснения.
- `MAY` — допустимое расширение.
- `CURRENT` — подтверждено текущей реализацией.
- `PLANNED` — зафиксировано, но ещё не завершено.
- `BLOCKED` — реализация существует, но обязательный acceptance не пройден.

## Поддерживаемые входы

Канонический набор расширений текущей реализации:

`.aac`, `.flac`, `.m4a`, `.mp3`, `.mp4`, `.ogg`, `.wav`, `.webm`.

Расширение списка требует теста нормализации через поставляемый FFmpeg.

## Ограничения текущей модели выполнения

- одновременно обрабатывается одна файловая задача;
- веб-состояние задачи хранится в памяти одного процесса;
- максимальный HTTP upload настроен на 20 GiB;
- прогресс внутри GigaAM оценивается по этапам и не является точным процентом
  инференса;
- diarization определяет условные кластеры, а не личности;
- результат ASR не гарантирует дословную точность и требует пользовательской
  проверки в ответственных сценариях;
- realtime ASR ещё не реализован.

## Требования к совместимости

- старый кэш GigaAM `~/.cache/gigaam` поддерживается как fallback, пока не
  введена проверенная миграция;
- существующие пользовательские данные не удаляются обновлением;
- изменение пути, имени файлов, bundle ID или JSON schema требует миграционного
  плана;
- расширение JSON должно быть обратно совместимым внутри major schema, если
  иное не оформлено отдельным ADR.

## Definition of Done для требования

Требование считается `CURRENT`, только если:

1. поведение реализовано;
2. есть автоматическая или ручная проверка;
3. пользовательская ошибка обработана;
4. затронутые документы обновлены;
5. для риска приватности или релиза выполнена соответствующая проверка из
   `09_QUALITY_AND_ACCEPTANCE.md`.
