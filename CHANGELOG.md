# История изменений

## 0.2.3 — 2026-08-10

- исправлено сопоставление голосовых embeddings с полным списком спикеров
  pyannote в realtime-режиме;
- единичная ошибка realtime-диаризации больше не останавливает распознавание,
  а проблемный фрагмент сохраняется со спикером «не определён»;
- повторяющиеся названия записей получают общий индекс для TXT, JSON и DOCX,
  поэтому предыдущие результаты не перезаписываются;
- готовый DOCX можно сразу показать в Finder;
- сохранение копии в существующий путь выполняется через временный файл и
  атомарную замену, а в «Загрузках» заранее предлагается свободное имя.

## 0.2.2 — 2026-08-04

- восстановлен системный диалог выбора записи в нативном окне macOS;
- восстановлено скачивание готовых TXT, DOCX и JSON с выбором папки сохранения.

## 0.2.1 — 2026-08-04

- интерфейс перенесён из вкладки браузера в отдельное окно macOS с Dock-иконкой;
- realtime-сессия продолжает работать при переключении или закрытии окна;
- системный звук realtime-разделяется по анонимным спикерам;
- микрофон сделан явным опциональным источником и выключен по умолчанию;
- добавлена защита от случайного завершения realtime-встречи;
- обновлена внутренняя DMG-сборка для Apple Silicon и macOS 15+.

## 0.2.0 — 2026-07-20

- добавлено самостоятельное macOS-приложение с постоянным bundle ID
  `com.ainikitadanik.transcriber` и запуском без Terminal;
- приложение управляет встроенным runtime и штатно завершает все дочерние
  процессы;
- realtime-захват системного звука и микрофона выполняется главным
  executable приложения, чтобы разрешения macOS относились к одной
  идентичности;
- добавлены purpose strings для микрофона и системного аудио, privacy-документ,
  ведомость компонентов и полные лицензии пакетов;
- GPL-сборка FFmpeg заменена минимальной сетево-отключённой сборкой
  LGPL-2.1-or-later; в приложение включаются её исходники и конфигурация;
- продуктовая сборка FFmpeg поддерживает вывод raw PCM `s16le` через локальный
  `pipe`, необходимый GigaAM для чтения подготовленного аудио;
- потоковое realtime-распознавание пока не объявляется готовым: текущий этап
  закрывает захват и локальную буферизацию PCM.

## 0.1.1 — 2026-07-16

- добавлена пользовательская установка из DMG без прав администратора;
- после проверки контрольных сумм установщик снимает карантин macOS с
  внутреннего ad-hoc runtime;
- готовая сборка включает Python runtime, FFmpeg и модели GigaAM RNNT/CTC;
- модели pyannote загружаются пользователем отдельно с личным Hugging Face
  Read-токеном;
- транскрибация, записи и результаты остаются локальными.

## 0.1.0

- локальная транскрибация аудио и видео в TXT, DOCX и JSON;
- последовательное объединение нескольких частей встречи;
- восстановление длинных пропусков, обработка тихих голосов и опциональное
  разделение по спикерам;
- локальный веб-интерфейс и запуск через `.command`.
