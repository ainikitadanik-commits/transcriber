# Транскрибатор 0.1.1

Первая версия для передачи коллегам в виде готового DMG.

## Установка

1. Скачайте `Transcriber-0.1.1-macOS-arm64.dmg`.
2. Откройте DMG.
3. Нажмите правой кнопкой на `Установить транскрибатор.command`, выберите
   «Открыть» и подтвердите запуск.
4. После сообщения «Готово» извлеките DMG.
5. Запускайте файл:
   `~/Applications/Транскрибатор/Запустить транскрибатор.command`.

Права администратора не требуются. Сборка предназначена для Mac с Apple
Silicon.

## Приватность

Записи и результаты остаются на Mac пользователя. Интернет нужен при первом
запуске только для загрузки моделей pyannote с Hugging Face после принятия их
условий. Личный Read-токен не сохраняется приложением.

## Известное ограничение

Пилотная сборка подписана локальной ad-hoc подписью, но не нотарифицирована
Apple. Поэтому macOS может потребовать запуск установщика через правую кнопку
мыши → «Открыть».
