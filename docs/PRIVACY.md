# Локальная обработка и приватность

## Что остаётся на Mac

Аудио- и видеозаписи, промежуточные файлы, тексты транскрибаций, DOCX и JSON
обрабатываются локально и сохраняются только в папке текущего пользователя:

```text
~/Library/Application Support/Транскрибатор
```

Веб-интерфейс слушает только локальный адрес `127.0.0.1` и не публикуется в
локальную сеть или интернет.

## Когда требуется интернет

В готовый DMG входят runtime, FFmpeg и модели GigaAM. При первом использовании
приложение обращается к Hugging Face только для загрузки разрешённых
пользователем моделей pyannote.

Пользователь самостоятельно принимает условия моделей и вводит личный token с
правом `Read`. Приложение:

1. использует token только в памяти текущего процесса;
2. не сохраняет token в конфигурацию или `.env`;
3. загружает необходимые файлы моделей;
4. удаляет token из окружения процесса;
5. включает офлайн-режим до обработки записи.

Запись не передаётся в Hugging Face. Hugging Face используется как источник
файлов моделей, а не как сервис транскрибации.

## Телеметрия

Для Hugging Face Hub устанавливается `HF_HUB_DISABLE_TELEMETRY=1`. Собственной
аналитики, облачного API транскрибации и удалённого хранилища у приложения нет.

## Ответственность пользователя

Пользователь должен соблюдать внутренние правила работы с записями и
персональными данными, контролировать доступ к своей учётной записи macOS и
удалять ненужные исходные записи и результаты из локальной рабочей папки.
