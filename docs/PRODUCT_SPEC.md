# Продуктовая упаковка «Транскрибатора»

## Назначение

Полностью локальное macOS-приложение для файловой транскрибации встреч и
рилтайм-захвата системного звука и микрофона. После первоначальной загрузки
моделей аудио, видео и текст не передаются во внешние сервисы.

## Постоянная идентичность

- имя продукта: `Транскрибатор`;
- bundle ID: `com.ainikitadanik.transcriber`;
- минимальная система: macOS 15;
- архитектура первой версии: Apple Silicon;
- пользовательские данные:
  `~/Library/Application Support/Транскрибатор`;
- установка без администратора: `~/Applications/Транскрибатор.app`.

Bundle ID считается постоянным контрактом. Его изменение приведёт к повторному
запросу системных разрешений.

## Разрешения

Приложение запрашивает только:

- микрофон — для голоса пользователя;
- системный звук и запись экрана — для речи собеседников через ScreenCaptureKit.

В `Info.plist` зафиксированы `NSMicrophoneUsageDescription` и
`NSAudioCaptureUsageDescription`. Рилтайм-захват выполняет тот же executable,
который является точкой входа `.app`, поэтому macOS видит одну идентичность.

## Процессы и данные

- Swift-executable запускает локальный Python-runtime и открывает
  `http://127.0.0.1:7860`;
- runtime слушает только loopback-интерфейс;
- Swift-executable также работает как дочерний realtime-процесс;
- PCM передаётся через локальные pipe-каналы;
- исходный рилтайм-поток не записывается на диск;
- меню приложения позволяет открыть интерфейс, папку результатов и завершить
  все локальные процессы.

Текущий realtime-этап подтверждает захват и буферизацию PCM. Потоковое
распознавание накопленных чанков GigaAM и заполнение живого текста остаются
отдельным обязательным этапом перед объявлением realtime-режима готовым.

## Лицензии

- полные лицензии фактически включённых Python-пакетов извлекаются из
  собранного runtime;
- FFmpeg собирается отдельно в минимальной конфигурации LGPL-2.1-or-later,
  без сети, внешних библиотек, GPL- и nonfree-компонентов;
- вместе с FFmpeg поставляются исходный архив, текст LGPL и конфигурация;
- условия и источники моделей перечислены отдельно;
- до публичного выпуска необходимо указать юридического правообладателя
  собственного кода и утвердить пользовательское лицензионное соглашение.

## Подпись и выпуск

Локальная разработческая сборка может использовать ad-hoc подпись. Для
полноценного распространения необходимы:

1. сертификат `Developer ID Application`;
2. hardened runtime;
3. подпись всех вложенных Mach-O и итогового `.app`;
4. нотариализация Apple;
5. stapling нотариального билета;
6. проверка Gatekeeper на чистой пользовательской учётной записи.

На текущем Mac постоянная code-signing identity отсутствует. До её появления
сборка может использоваться для локальной приёмки, но не считается готовой к
внешнему распространению.

## Критерии продуктовой готовности

- двойное нажатие по `.app` запускает интерфейс без Terminal;
- разрешения привязаны к постоянному bundle ID;
- файловая транскрибация работает локально;
- рилтайм-захват выдаёт два локальных PCM-потока, а потоковое распознавание
  закрыто отдельной приёмкой;
- приложение корректно завершается из строки меню;
- присутствуют privacy-документы и лицензии всех распространяемых компонентов;
- DMG устанавливается без администратора;
- подписанный и нотариализованный релиз проходит Gatekeeper.
